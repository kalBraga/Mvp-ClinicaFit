# Mvp-ClinicaFit
MVP ClinicaFit: Web app híbrido focado no engajamento e bem-estar para clínicas de estética. Conta com chat assistente integrado à IA (Gemini/GPT), diário de hábitos, triagem inteligente para agendamentos e registro de evolução física dos pacientes. Desenvolvido com a robustez do ecossistema .NET (C#) em arquitetura Web API.
