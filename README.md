# 🏥 Clinica Fit - Assistente Híbrido de Engajamento e Bem-Estar

O **ClinicaFit** é um MVP (Mínimo Produto Viável) de uma aplicação web híbrida focada no ecossistema de clínicas de estética e bem-estar, pensada esclusivamente para uma franquia de uma grande rede de estetica. O sistema atua como um assistente digital para aumentar o engajamento, a motivação e o suporte pontual dos pacientes entre as consultas presenciais.

O grande diferencial do projeto é a integração nativa com modelos de Inteligência Artificial de alta eficiência ( Gemini 2.5 Flash-Lite ) para humanizar e agilizar o atendimento.

---

## 🚀 Funcionalidades Principais

* **💬 Chat de Suporte Pontual (IA):** Um assistente virtual inteligente disponível 24/7 para tirar dúvidas comuns sobre procedimentos, dar suporte motivacional e auxiliar o paciente a manter o foco no plano de bem-estar.
* **📈 Registro de Evolução:** Módulo focado no acompanhamento de métricas físicas (como peso, medidas e evolução do IMC), permitindo que o usuário veja seu progresso de forma gráfica e clara.
* **📅 Diário de Hábitos:** Uma área interativa para o paciente registrar suas rotinas diárias (hidratação, alimentação e atividades), promovendo a autodisciplina.
* **📋 Triagem e Agendamento:** Fluxo inteligente que realiza uma pré-triagem das necessidades do cliente e facilita o direcionamento para o agendamento de consultas ou avaliações presenciais na clínica.

---

## 🛠️ Tecnologias e Arquitetura

O projeto foi estruturado seguindo os padrões de desenvolvimento de mercado, garantindo separação clara de responsabilidades (Clean Architecture):

* **Backend:** .NET Core (C#) utilizando Web API RESTful, injeção de dependência e integração com APIs de Large Language Models (LLMs).
* **Frontend:** Aplicação Web Híbrida / Blazor (C#) focada em uma experiência de usuário (UX) fluida e responsiva para dispositivos móveis.
* **Solução:** Organizada via arquitetura de múltiplos projetos gerenciados por uma Solution (`.sln`) unificada.
